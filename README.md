# Grape TV 🎮

Grape TV is a fully responsive movie browsing application built with React. This project demonstrates modern frontend development techniques, including API integration, state management, dynamic routing, and deployment.

The application consumes data from **The Movie Database API (TMDb)** to allow users to:

* Search for movies
* Browse trending movies
* Explore movies by category
* View detailed information about selected movies

---

## 🌟 Features

* Real-time movie search functionality
* Dynamic category filtering
* Trending movies carousel with horizontal scrolling
* Detailed movie pages with descriptions, scores, and genres
* Fully responsive design for mobile and desktop
* Dynamic client-side routing with React Router
* Reusable React components architecture
* Custom React hooks for clean data fetching
* Error Boundaries for improved error handling
* Continuous deployment to Netlify

---

## ⚙️ Tech Stack

* **React** (Single Page Application)
* **Vite** (Build tool and development server)
* **React Router** (Dynamic client-side routing)
* **Axios** (HTTP client for API requests)
* **TailwindCSS** (Utility-first CSS framework)
* **The Movie Database API (TMDb)** (External API for movie data)
* **Netlify** (Hosting and deployment)

---

## 📊 Architecture Overview

* **Component-based structure**: Clean, reusable components for maintainable code.
* **Custom Hooks**: `useGetData` and `useSearch` to handle API requests and search logic.
* **Dynamic Routing**: React Router handles navigation between homepage, search results, categories, and movie detail pages.
* **Error Handling**: Error Boundaries wrap key components to prevent crashes.
* **Deployment Workflow**: Optimized build with Vite, continuous deployment to Netlify.
